# 广东药科大学官网

这是一个使用React构建的现代化大学官网，采用极简设计风格，主题色为蓝色。

## 功能特性

- 🏠 首页展示
- 📖 关于我们
- 🏫 学院设置
- 📰 新闻动态
- 📞 联系我们
- 📱 响应式设计，支持移动端

## 技术栈

- React 18
- React Router DOM
- React Icons
- CSS3
- 响应式设计

## 在线访问

网站地址：[https://bitong1202.github.io/my-ku](https://bitong1202.github.io/my-ku)

## 本地运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm start

# 构建生产版本
npm run build
```

## 部署

使用GitHub Pages自动部署：

```bash
# 部署到GitHub Pages
npm run deploy
```

## 项目结构

```
src/
├── components/          # React组件
│   ├── Header.js       # 头部导航
│   ├── Hero.js         # 首页轮播
│   ├── About.js        # 关于我们
│   ├── Schools.js      # 学院设置
│   ├── News.js         # 新闻动态
│   ├── NewsDetailPage.js # 新闻详情页
│   ├── Contact.js      # 联系我们
│   └── Footer.js       # 页脚
├── App.js              # 主应用组件
└── index.js            # 应用入口
```
